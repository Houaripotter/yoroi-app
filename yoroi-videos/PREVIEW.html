📦 Rendre les vraies vidéos MP4

1. Ouvre le terminal dans ton dossier app :
cd /Users/houari/Documents/APP_Houari/yoroi_app/yoroi-videos
2. Installe les dépendances :
npm install
3. Lance le studio Remotion pour preview live :
npx remotion studio
4. Ou render directement en MP4 :
npx remotion render YoroiTrailer out/trailer.mp4
npx remotion render YoroiFeatures out/features.mp4
⚡ Les vidéos sortiront en 1080×1920 (9:16) — format parfait pour TikTok et Instagram Reels.
Remotion télécharge Chrome automatiquement la première fois (~200MB).
Temps de rendu : ~2min par vidéo.
