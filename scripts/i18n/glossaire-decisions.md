# YOROI : décisions de terminologie (harmonisation)

Ces choix s'imposent à toutes les traductions. Ils complètent consignes-traducteurs.md.
Format : français : anglais / allemand / néerlandais

1. coffre (rangement des photos ou des données santé) : vault / Tresor / kluis
2. coffre (récompense du dojo, grand coffre, coffre à ouvrir) : chest / Truhe / kist
3. joker (sauve une semaine de série) : wildcard / Joker / joker
4. cap (poids visé) : target / Ziel / doel. Date du cap : target date / Zieldatum / streefdatum
5. bête noire : nemesis / Angstgegner / aartsrivaal (jamais Angstgegner en néerlandais)
6. palmarès : record / Kampfbilanz / erelijst
7. catégorie (de poids) : weight class / Gewichtsklasse / gewichtsklasse
8. plaque (d'armure, à encrer) : plate / Platte / plaat
9. sceau : seal / Siegel / zegel
10. créneau : slot / Slot / tijdslot
11. coupe de poids : weight cut / Weight Cut / weight cut. Coupe d'eau : water cut / Water Cut / water cut
12. soumission, finition : submission / Submission / submission
13. personnage : character / Figur / personage
14. suivi (élément suivi dans le carnet) : tracker / Tracker / tracker
15. infirmerie : infirmary / Krankenstation / ziekenboeg
16. mode créateur : creator mode / Creator-Modus / makersmodus
17. quête : quest / Quest / missie. Défi : challenge / Challenge / uitdaging
18. mode épuré : minimal mode / Minimalmodus / minimale modus
19. copie de sécurité, sauvegarde : backup / Backup / back-up
20. Jour J : Fight day / Kampftag / Wedstrijddag. J moins 30 : 30 days out / noch 30 Tage / nog 30 dagen
21. Mot de confirmation SUPPRIMER (à taper) : DELETE / LÖSCHEN / VERWIJDEREN
22. kimono : gi / Gi / gi. Sans kimono : no-gi / No-Gi / no-gi
